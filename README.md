# Walerys Labs

My personal laboratory for software, hardware, and better ways of working.
Experiments, practical lessons, and things worth understanding.

**Read the blog: https://labs.walerys.app**

Built with [Astro](https://astro.build/), written in Markdown, and published to
GitHub Pages through GitHub Actions.

## Local development

Requires Node.js 24 and npm.

```sh
npm ci
npm run check
npm run build
npm run preview
```
